# Обработка чеков Google Диска — тестовая версия

**Не подключено к основному сайту.** Код не должен автоматически менять операции, остатки или расходы, пока не подтверждена сверка.

## Источники
- Папка чеков: https://drive.google.com/drive/folders/1fpJgRM7uL_ST2sOcmjtExLzKIbP4H1G3
- Таблица черновиков: https://docs.google.com/spreadsheets/d/1OdgX59VTCm37jejrXWKgOu0aNgJSHFCoB6MjGQXdKHw/edit

## Однократная настройка
1. Создать проект https://script.google.com/ под тем же Google-аккаунтом.
2. Скопировать Code.gs в редактор; добавить сервис Google Drive API (Advanced Google Service).
3. Project Settings → Script properties:
   - RECEIPTS_FOLDER_ID = 1fpJgRM7uL_ST2sOcmjtExLzKIbP4H1G3
   - LEDGER_SHEET_ID = 1OdgX59VTCm37jejrXWKgOu0aNgJSHFCoB6MjGQXdKHw
4. Один раз запустить scanNewReceipts и одобрить доступ Google.
5. Проверить извлечение текста на реальном тестовом чеке. Лишь после этого запустить installHourlyTrigger.

## Что делает
- Читает изображение или PDF, включая текст товарных строк, если распознавание удалось.
- Защищает от повторного импорта **того же файла по Drive file ID**.
- Добавляет черновик в таблицу и отмечает нераспознанное.
- Не проводит сумму в семейные расходы автоматически.

## Что пока НЕ делает
- Не разбивает надёжно все товарные строки по категориям.
- Не выявляет идентичные чеки, загруженные как разные файлы.
- Не сопоставляет покупки с банковской выпиской.
- Не записывает данные обратно на сайт и не гарантирует сохранение остатков.
- Не удаляет и не перемещает исходные файлы.

## Перед включением полноценной схемы
Добавить структуры «покупка → товарные позиции», проверку одинаковых чеков по содержимому,
сопоставление с банковскими списаниями и защищённую синхронизацию сайта.
